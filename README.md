# Trust, 5C Constructs, and Influenza Vaccination Uptake Among Nurses

## Overview

This repository contains the analysis-specific dataset and R code used to reproduce the **effect-modification, path, and sensitivity analyses** examining trust in health information sources, the 5C psychological antecedents of vaccination, and influenza vaccination uptake among nurses in **Brunei, Hong Kong, and Singapore**.

The repository contains only variables required for the analyses presented here. Prespecified participant exclusions and variable derivations were completed before creation of the shared analysis dataset. Participant identifiers and variables unrelated to these analyses are not included.

---

## Repository Contents

The repository contains the following files:

- `Nurses_analysis_data.RDS`: analysis-specific dataset used for the reported analyses.
- `modification_analysis.R`: R code for the effect-modification analyses.
- `path_analysis.R`: R code for the path analyses and Singapore main-effect sensitivity analyses.
- `README.md`: description of the dataset and analyses.

---

## Dataset

### `Nurses_analysis_data.RDS`

`Nurses_analysis_data.RDS` is an analysis-specific dataset containing only variables required to reproduce the analyses in this repository.

The original study dataset is not included in this repository.

Prespecified participant exclusions and required variable derivations were completed before creation of this analysis-specific dataset. Participant identifiers and study variables unrelated to the analyses reported here were removed.

---

## Variable Description

The following variables are contained in `Nurses_analysis_data.RDS`.

| Variable | Description | Coding / scale |
|---|---|---|
| `agegp` | Age group | Categorical age group |
| `sex` | Sex | Categorical |
| `lti` | Long-term illness | Categorical; long-term illness status |
| `site` | Study population/site | BRN = Brunei; HKG = Hong Kong; SGP = Singapore |
| `tr_gw3` | Trust in government websites | Three-category trust variable: Low, Moderate, High |
| `tr_sm3` | Trust in social media | Three-category trust variable: Low, Moderate, High |
| `tr_ai3` | Trust in AI chatbots | Three-category trust variable: Low, Moderate, High |
| `tr_fd3` | Trust in family doctors | Three-category trust variable: Low, Moderate, High |
| `tr_ff3` | Trust in family/friends | Three-category trust variable: Low, Moderate, High |
| `tr_gw` | Trust in government websites | Continuous trust score on the original 1–7 scale |
| `tr_sm` | Trust in social media | Continuous trust score on the original 1–7 scale |
| `tr_ai` | Trust in AI chatbots | Continuous trust score on the original 1–7 scale |
| `tr_fd` | Trust in family doctors | Continuous trust score on the original 1–7 scale |
| `tr_ff` | Trust in family/friends | Continuous trust score on the original 1–7 scale |
| `vh_conf` | Confidence | Mean score for the Confidence construct |
| `vh_comp` | Complacency | Mean score for the Complacency construct |
| `vh_cons` | Constraints | Mean score for the Constraints construct |
| `vh_calc` | Calculation | Mean score for the Calculation construct |
| `vh_coll` | Collective responsibility | Mean score for the Collective Responsibility construct |
| `flu_uptake` | Influenza vaccination uptake | Original categorical vaccination-uptake variable |

The analysis code additionally derives the following binary outcome from `flu_uptake`:

| Derived variable | Description | Coding |
|---|---|---|
| `flu_uptake_bin` | Binary influenza vaccination uptake | 1 = received influenza vaccination; 0 = did not receive influenza vaccination |

`flu_uptake_bin` is generated by the analysis code and therefore does not need to be stored separately in the shared RDS file.
